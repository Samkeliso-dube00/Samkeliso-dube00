## 👋 About Me

Hi, I'm **Samkeliso Dube**, a Junior DevOps and Cloud Engineer from Zimbabwe. I studied **Cloud Engineering at AltSchool Africa**, where I developed a foundation in cloud technologies and DevOps practices.

I'm interested in how cloud infrastructure, automation and application deployment work together. I learn by building projects, troubleshooting problems and documenting what I learn.

I completed a DevOps internship with The CloudAdvisory Oy, where I gained practical exposure to DevOps tools, technologies and workflows. I'm now strengthening those skills through independent projects, hands-on labs and technical documentation.

My areas of interest include:
- ☁️ Cloud infrastructure and AWS services.
- 🐧 Linux administration, Bash and networking.
- ⚙️ Infrastructure as Code and configuration management.
- 🐳 Containerisation and orchestration.
- 🔄 CI/CD and deployment automation.
- 📝 Technical documentation and troubleshooting.
